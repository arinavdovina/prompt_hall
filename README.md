# THE GREAT PROMPT HALL — адвент 1–24 декабря 2026

Статический сайт с 24 свечами для публикации на **GitHub Pages**. Сохранены оригинальный фон, 24 изображения свечей, пламя, анимация свечей, эффект светящегося курсора GlowCursor и окно с тремя карточками промптов. React, npm и сборка не нужны.

**Все 24 дня намеренно пустые.** В календаре нет ни одного готового промпта. После наступления даты открытая свеча будет показывать три пустые карточки с выключенными кнопками копирования. Когда добавите текст в файл с промптами, соответствующая кнопка станет активной.

## Расписание (московское время)

- Старт: **1 декабря 2026 года, 10:00 МСК**.
- Каждый следующий день открывается ровно в **10:00 МСК**.
- Последний, 24-й день: **24 декабря 2026 года, 10:00 МСК**.
- До начала календаря все 24 свечи видны, но закрыты.
- После открытия предыдущие свечи остаются доступными.

## Публикация на GitHub Pages

1. Распакуйте ZIP на компьютере.
2. Создайте новый репозиторий на GitHub (например, `great-prompt-hall`).
3. Загрузите **содержимое** папки сайта в корень репозитория (файл `index.html` и папки `css`, `js`, `content`, `assets`, а также `.nojekyll`). **Не загружайте на Pages один ZIP вместо содержимого.**
4. Сохраните файлы кнопкой **Commit changes**.
5. В **Settings → Pages** выберите **Deploy from a branch** → ветка `main` → папка `/(root)` → **Save**.
6. Адрес обычно будет `https://ВАШ-ЛОГИН.github.io/great-prompt-hall/` при совпадении с названием репозитория.

## Как позже добавлять промпты

**Редактируется только файл [`content/prompts.js`](content/prompts.js)**. В нём есть все 24 дня, и каждый содержит три пустые карточки:

```js
  // 1 декабря
  1: {
    title: '',
    description: '',
    prompts: [
      { title: '', text: '' },
      { title: '', text: '' },
      { title: '', text: '' },
    ]
  },
```

Например, чтобы заполнить только первую карточку 1 декабря, замените её на:

```js
{ title: 'Первый промпт', text: `Напиши сюда полный текст промпта.
Можно писать на нескольких строках.` },
```

Остальные карточки и дни могут остаться пустыми. В GitHub можно открыть `content/prompts.js`, нажать карандаш (Edit), добавить тексты и сохранить (Commit changes). **Не меняйте номера дней** и следите за кавычками и запятыми. Дата открытия не зависит от наполнения.

## Предпросмотр до 1 декабря

Для локальной проверки интерфейса:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/?preview=all` — все свечи станут кликабельными **только для теста на localhost**, но карточки останутся пустыми. Без `?preview=all` действует календарь и все будущие дни закрыты. Режим предпросмотра не работает на опубликованном GitHub Pages.

## Изображения: все внутри ZIP

**Все 26 оригинальных изображений включены в архив**. Сайт загружает изображения непосредственно из репозитория GitHub Pages и не зависит от Postimages:

- `assets/candles/01.png` — `24.png` — все 24 свечи;
- `assets/candles/flame.png` — картинка пламени на открытых свечах;
- `assets/candles/background.png` — фон Большого зала.

Пути собраны в `js/images.js`. Ничего менять не требуется. Загружайте на GitHub папку `assets` целиком, иначе изображения не появятся. **Публиковать нужно распакованные файлы, а не ZIP.**

## Структура проекта

- `index.html` — главная страница
- `css/style.css` — дизайн и адаптивность
- `js/app.js` — календарь, копирование, таймер, окна
- `js/config.js` — даты открытия и время 10:00 МСК
- `js/images.js` — ссылки на локальные и пока внешние изображения
- `assets/candles/` — все 24 свечи, пламя и фон внутри ZIP
- `js/glow-cursor.js` — светящийся курсор
- `content/prompts.js` — **24 пустых дня (редактировать для наполнения)**
- `assets/favicon.svg` — иконка
- `.nojekyll` — настройка GitHub Pages

**Ограничение:** проверка дат выполняется в браузере пользователя. Статический сайт не обеспечивает серверной защиты от обхода ограничений, а текст будущих промптов, добавленный заранее в общедоступный JavaScript-файл, технически можно прочитать через исходный код страницы. Для защищённого ежедневного раскрытия понадобится серверная часть.
